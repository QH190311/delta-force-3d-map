# 三角洲行动 · 地图态势面板

把《三角洲行动》(DFM) 导出的 PhysX 场景 `.bin` 还原成可交互的 3D 地图,并支持实时喂入游戏坐标,在地图上标注玩家、物资、目标位置。

单文件页面,零构建,零外部依赖。

## 特性

| 特性 | 说明 |
|---|---|
| 格式解析 | 浏览器内直接解析 TIMEPX01,无需预处理。最大图(AZ3,30MB)约 30ms |
| 6 张地图 | 长弓溪谷 / 零号大坝 / 航天基地 / AZ3 / 巴别神 / 大厅 |
| 地形还原 | 瓦片拼接 + 离线求解的摆放参数,与建筑对齐 |
| 实时标注 | 喂游戏坐标即可标出队友 / 敌人 / 物资 / 目标 |
| 自由相机 | 第一人称转视角(地图不动),支持键鼠与触屏 |
| 移动端 | 横屏布局 + 虚拟摇杆,触屏手势完整支持 |
| 性能可调 | 画质三档,相机速度三条独立滑条 |

## 快速开始

### 本地

双击 `start.bat`,自动打开浏览器。关掉黑窗口即停止服务。

> 若打不开,先双击 `stop.bat` 清理残留,再启动。

## 实时坐标接入

页面暴露 `window.GameMap`,喂入**游戏坐标(厘米,Z 轴向上)**:

```js
GameMap.push([
  { kind: 'enemy', x: -100000, y: 50000, z: 2000, name: '敌人A' },
  { kind: 'ally',  x:  -80000, y: 60000, z: 2000, name: '队友B' },
], 'my-source');   // 第二参数是数据源 ID,重复推送会覆盖同一源
```

`kind` 可取 `ally` / `enemy` / `loot` / `obj`。

`GameMap.clear()` 清空标注。

坐标精度已做往返验证,误差为 0(画面位置与游戏坐标可精确互换)。

## 已知限制

**1. 这是物理碰撞几何,不是美术模型**

面数按物理精度生成,不是给渲染用的 —— AZ3 的建筑有 615 万三角面。因此默认使用线框模式,实体模式下会有明显卡顿(小场景如长弓溪谷尚可)。

**2. 地形摆放依赖离线求解**

相关系数在 0.25 ~ 0.92 之间。瓦片不含位置信息,位置由「建筑底面高度与脚下地形高度的相关性」反推,相关性低的图(如航天基地 0.25)地形可能与建筑存在偏移。

**3. 地图数据体积较大**

共 110MB。受服务器带宽限制(约 600KB/s),首次加载 AZ3 需约 50 秒,页面已提供进度与速度显示。

**4. 需要硬件加速**

若 GPU 显示 `Microsoft Basic Render`(WARP),说明浏览器在使用 CPU 软件渲染,性能会下降数十倍。页面会自动降级并提示。解决办法是开启浏览器硬件加速,或避免通过远程桌面访问。
